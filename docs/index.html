🧼 CIP 清洗效益 QC 資料治理 POC

本 POC 展示工廠 CIP（原地清洗）作業的 QC 紀錄如何從髒亂的原始資料（多種日期格式、欄位錯置、空值） 匯入、治理，並轉成可監控的達標率看板。下方依序為系統架構、資料品質提醒，以及即時統計儀表板。

系統架構（輸入 → 資料 → 邏輯 → 輸出）

flowchart LR
  subgraph Input[輸入層]
    S1[CIP紀錄輸入
表單/人工/匯入]
    S2[感測/自動資料
流量/導電度/pH/溫度]
  end
  subgraph Data[資料層]
    T1[(CIP紀錄表 Fact)]
    T2[(基準/目標表 Baseline)]
    T3[(異常與改善表 CAPA)]
  end
  subgraph Logic[邏輯層]
    L1[規則計算
節水率/節時率/FPY/成本]
    L2[達標判定
閾值/權重/紅黃綠]
  end
  subgraph Output[輸出層]
    O1[達標率看板]
    O2[趨勢圖]
    O3[異常清單]
  end
  S1 --> T1
  S2 --> T1
  T2 --> L1
  T1 --> L1 --> L2
  L2 --> O1
  L1 --> O2
  L2 --> T3 --> O3
⚠️ 資料品質提醒：原始 QC-008 資料存在 多種日期格式（20260101、2 Mar 2026、2026/1/1、2026-05-05）、 欄位錯置與空值。實務上需先經資料清理與欄位標準化，下方儀表板直接呈現原始資料的分佈，凸顯治理需求。
